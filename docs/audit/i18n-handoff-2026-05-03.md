## Workflow per stránka

1. **Read page** → identifikuj hardcoded texty
2. **Add 5-lang keys** do `src/i18n/ui.ts` (jeden Edit per lang block, batch keys)
3. **Rewrite page** používající `t('key')`
4. **`npm run build`** — verify (267 stránek se má vygenerovat)
5. **Verify per-lang** — `grep` na `dist/{en,de,sk,uk}/page/index.html`
6. **Commit + push** do `main` — triggers WebGlobe deploy přes GitHub Actions
7. **Update todo** — mark completed, set next as in_progress

## Pattern pro klíče

```typescript
// CS (zdroj)
'page.xxx.title': 'Název',
'page.xxx.subtitle': 'Podtitulek',
'page.xxx.description': 'Meta description',

// Inline link (NE set:html, NE template literals s HTML):
'page.xxx.body_pre': 'Text před linkem ',
'page.xxx.body_link': 'Text linku',
'page.xxx.body_post': ' a text za linkem.',
```

V Astro stránce:
```astro
<p>
  {t('page.xxx.body_pre')}<a href={`/${lang}/cesta/`} class="underline">{t('page.xxx.body_link')}</a>{t('page.xxx.body_post')}
</p>
```

## Pro právní stránky

Použij globální klíč `legal.jurisdiction_notice` (existuje v 5 jazycích). Pro non-cs zobrazí AlertBox:

```astro
{lang !== 'cs' && (
  <AlertBox variant="info" class="mb-6">
    {t('legal.jurisdiction_notice')}
  </AlertBox>
)}
```

Důvod: User explicitně chtěl notice o ČR jurisdikci + plný překlad pro **všechny** právní texty.

## Pro velké strukturované obsahy

Vytvoř separátní soubor `src/data/{name}.ts` s typovanou funkcí `getXxx(lang: Lang)` vracející `T[]`. Příklad: `src/data/faq.ts` s `getFaqGroups(lang)`. Helper `L = (path) => /${lang}${path}` se předá dovnitř pro skládání URL.
